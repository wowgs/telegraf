# Страница

Как устроена страница плагина `outputs.hostdash`. Главная дока — [Дизайн](design.md); данные и API — [Плагин hostdash](plugin.md).

## Решения

- Графики рисует uPlot 1.6.32. Файлы лежат в `page/vendor/` и вшиваются в бинарь: страница работает без интернета. Файлы совпадают с пакетом `uplot-1.6.32.tgz` из npm, SHA-512 пакета совпадает с `integrity` в реестре.
- Время и окно выбираются только вверху страницы и действуют на все графики сразу. На отдельном графике своего масштаба нет.
- Фильтрация и группировка — по тегам. У каждого measurement свои теги, поэтому фильтр и группировка свои у каждой секции. Строки поиска и переключателя «только проблемы» нет.
- У каждой секции одна строка запроса: выбранные фильтры и группировки видны в ней чипами, крестик снимает условие. Фильтровать и группировать можно по любым тегам measurement, группировать — по нескольким сразу.
- Все графики по умолчанию рисуют все линии, по одной на серию; группировку, с которой секция открывается, задаёт конфиг секции (`group_by` или `group_without`, `agg`).
- Группировка — со смыслом PromQL: у блока группировки два режима, `by` и `without` (раздел «Группировка»).
- `band` — одно из сведений в блоке группировки наряду с `avg`, `min`, `max`, `sum`, а не отдельный режим графика: каждая линия группы рисуется полосой min–max своим цветом и средней линией; одно число (плитка, заметка) при `band` — среднее.
- Stacked — только опция графика (`stacked = true`), по умолчанию выключен.
- Measurement без секции рисуется такой же карточкой, как остальные: график на каждое числовое поле, плитка на текстовое. Такие карточки по умолчанию свёрнуты.
- Смена параметров на странице не сдвигает её прокрутку.
- Overview перечисляет секции каждой вкладки из конфига: те же названия, тот же порядок и те же ссылки, что на вкладке.
- У секции есть адрес `#<вкладка>/<measurement>`, как якорь заголовка в Markdown.
- Подписи страницы — на английском.

## Верх страницы

- Заголовок (`title` плагина, по умолчанию имя хоста), панель времени, статус: `connecting…` до первого ответа, `live` и число серий, `Telegraf sends nothing` (silent), `offline — retrying` (запрос к плагину не прошёл), `page error, see the console` (ошибка самой страницы при отрисовке). Шапка закреплена.
- Панель времени: 5, 15, 30 мин, 1, 3, 6, 12, 24 ч — только те, что не больше окна сервера.
- Вкладки: Overview, затем вкладки из конфига в его порядке, и те, у которых ещё нет данных. У вкладки, где худший статус не `ok`, — точка цвета статуса; для программ чтения с экрана статус ещё и текстом. Вкладки — `role="tab"` с `aria-selected`, кнопки времени — с `aria-pressed`.
- Кнопки вкладок и времени создаются, только когда меняются вкладки или окно; ответы ленты обновляют их на месте, поэтому клик между нажатием и отпусканием мыши не теряется и фокус клавиатуры остаётся.

## Секция

Секция — сворачиваемая карточка: заголовок (ссылка на адрес секции с текущим видом страницы), статус секции, если он не `ok`, возраст последней точки, заметка (`note`), строка запроса, плитки и графики. Свёрнутость запоминается в браузере. Свёрнутая секция не запрашивается, поэтому возраста у неё нет. Секция конфига без данных — карточка с заголовком, статусом и строкой «No data yet.».

- **Заметка** (`note`) показывает значения первой серии секции, которую оставил фильтр, независимо от группировки.
- **Плитка** считает по сериям, а не по линиям строки запроса: последнее значение поля в каждой группе, которую оставил фильтр, затем `agg` плитки по группам (`first` — первая группа, по умолчанию; `max`; `sum`). Уровень `warn`/`bad` сравнивает с порогами значение, а с `of` — долю `поле / of` в той же группе, сведённую тем же `agg`, как проверка плагина (`tileValue` в `model.js`).

### Строка запроса

- Кнопка «+» в начале строки или клик по её свободному месту открывает меню: `filter`, `group by` и `group without` (когда группировка уже есть — вместо двух последних один пункт её режима), справа — ключи тегов measurement с числом значений.
- `filter` → ключ: в строке появляется блок `ключ = …` (блок доступен с клавиатуры: Tab и Enter), под ним окно значений: поле для ввода (значение или маска `*`, Enter) и список значений, которые есть сейчас; список отбирается по введённому: с `*` — как маска, без неё — по подстроке. Клик по значению добавляет или убирает его. Несколько значений — «или», несколько блоков — «и». Клик по `=` переключает на `≠`. Блок без значения после закрытия окна убирается.
- `group by` или `group without` → ключ: ключ добавляется в блок группировки (раздел «Группировка»). Клик по функции меняет её (`avg`, `min`, `max`, `sum`, `band`).
- Функция, когда группировку начинаете вы, — `band` (`withGroupTag` в `model.js`); со следующими тегами она остаётся. Если в конфиге секции группировка задана без `agg`, функция ставится по единице первого поля первого графика (`defaultAgg`): `sum` для скоростей, `count` и `tok`, `avg` для остального; `s/s` (доля времени) — `avg`.
- Справа — «N groups → M lines»: сколько групп (наборов тегов) подошло из всех и сколько линий на поле получилось. У изменённой относительно конфига секции есть кнопка ↺: она возвращает конфиг.
- Кнопка «band» у графика, где больше 8 линий, — ярлык: ставит в строку запроса `band by ()` — одна полоса min–max и средняя на всю секцию; «lines» убирает группировку. У stacked-графика кнопки нет, при `band` он рисует среднее.

### Группировка

Группировка сводит серии секции в линии, со смыслом PromQL (`keptTags`, `withGroupTag`, `withoutGroupTag`, `switchMode` в `model.js`).

- **Один блок на секцию:** `<функция> <режим> <теги>`, например `sum by cpu` или `avg without cpu, irq`. У одного сведения либо `by`, либо `without`, как в PromQL, поэтому противоречивого состояния нет.
- **`by`** — перечисленные теги остаются, всё остальное сводится функцией: одна линия на каждое сочетание их значений. `sum by cpu` — линия на ядро. **`by ()`** (без тегов) — одна линия на всю секцию.
- **`without`** — перечисленные теги убираются, остальные остаются: одна линия на каждое сочетание значений остальных тегов. `avg without cpu` — среднее по всем ядрам.
- **Без блока** — каждая серия своей линией.
- **Переключение режима:** клик по слову `by` или `without` в блоке. Теги остаются, меняется их смысл — как правка запроса в PromQL.
- **Теги:** новый тег из меню добавляется в блок в его режиме. Крестик у тега убирает его из блока; последний тег в режиме `by` оставляет `by ()`, последний в `without` убирает блок. Крестик у блока убирает группировку.
- **Конфиг секции** — `group_by` или `group_without` и `agg` ([Плагин hostdash](plugin.md#раскладка)).
- **Адрес:** `g.<sec>=теги` — `by` (пустое значение — `by ()`), `w.<sec>=теги` — `without`, `a.<sec>=функция`; `a.<sec>=none` — без группировки поверх конфига.
- **Подпись линии** — значения тегов, которые различают линии: в `by` — перечисленных, в `without` — остальных.

### График

- **Ось Y:** верх идёт за данными — максимум видимых данных плюс 10 %. `max` и `max_field` — потолок, выше которого ось не поднимается; `min_max` — высота, до которой ось поднимается всегда. Низ — `min`, иначе 0 или ниже, если данные ниже 0 (`yBounds` в `axis.js`). Подписи делений — одна функция для всех осей (`valueLabels`): полное значение в одном формате, один масштаб на ось, столько знаков, сколько нужно шагу; для байтов шаги двоичные (`incrs`).
- **Ось времени** — 24-часовая, от «сейчас» минус выбранное время до «сейчас». Пауза дольше трёх обычных шагов рвёт линию; у линии из двух точек обычный шаг берётся у других линий графика (`table` в `combine.js`).
- **Предел линий:** график рисует не больше `chart_lines` линий (опция плагина, по умолчанию 100) — те, у которых пик в видимом времени выше; полоса `band` считается одной линией. В шапке графика — «+N lines not drawn», подсказка советует фильтр или группировку.
- **Stacked:** линии складываются друг на друга; линия, скрытая кликом по легенде, в сумму не входит, слои выше неё опускаются.
- **Легенда** — плашки: отрезок цвета линии, подпись, значение (без курсора — последнее, с курсором — в его моменте). Линии с самым высоким пиком в окне идут первыми. По умолчанию легенда в одну строку, справа «+N ▾» с числом линий, которые не поместились; развёрнутая — ровная сетка всех линий, кнопка «less ▴». Выбор запоминается для каждого графика в браузере; легенда, которая помещается в одну строку, кнопки не имеет. Плашка — кнопка (`aria-pressed`): клик или Enter скрывает или показывает линию, скрытая — бледная и зачёркнутая, это тоже запоминается.
- **Наведение.** Курсор времени общий для всех графиков вкладки. Активная линия — ближайшая к курсору по вертикали (`cursor.focus.prox` uPlot), остальные бледнеют; на активной точка, в легенде её плашка выделена. Линия без точки ровно под курсором берёт ближайшую в пределах 16 px (`cursor.hover.prox`).
- **Попап:** время; активная линия с полными тегами таблицей «ключ — значение» (сначала свои теги, потом общие для всех линий, бледнее) и, если она сводит несколько серий, «avg of N series»; ниже линии в этот момент по убыванию значения — порядок сверху вниз совпадает с графиком. Список показывает до `tip_lines` строк (по умолчанию 20) вокруг активной и пишет, сколько ещё выше и ниже. ↑ и ↓ ходят по списку между линиями, которые лежат друг на друге.

## Overview

Сетка карточек, по одной на вкладку, в порядке вкладок. У карточки — название вкладки (ссылка на неё), худший статус её секций плашкой и полосой слева, секции вкладки чипами с точкой своего статуса в порядке конфига (ссылки на секции), под ними причины секций, которые не `ok`: «название секции: причина». Подсказка на чипе — статус и причины. Плиток на Overview нет. Что значат статусы — [Плагин hostdash](plugin.md#статусы).

## Адрес и состояние

- Адрес: `#<вкладка>` или `#<вкладка>/<measurement>`, после `?` — параметры: `t=<мс>` (выбранное время), `f.<sec>.<тег>=a,b*` (тег — одно из значений), `n.<sec>.<тег>=c` (тег — ни одно из них), `g.<sec>=тег,тег` (группировка `by`, пустое значение — `by ()`), `w.<sec>=тег,тег` (группировка `without`), `a.<sec>=max` (функция); `<sec>` — measurement секции. Имена и значения кодируются, `.` и `,` тоже. Такую ссылку можно отправить.
- В адрес пишутся только секции, которые вы поменяли относительно конфига. Если правка вернула секцию к конфигу, запись из адреса уходит. Функция пишется и тогда, когда изменена только она, а группировка как в конфиге. Фильтр без значений (окно значений ещё открыто) в адрес не пишется.
- Адрес с секцией открывает вкладку и один раз прокручивает к секции, под закреплённую шапку; свёрнутую секцию раскрывает. Если точки measurement вкладки у страницы уже есть, она прокручивает сразу, иначе — после ответа, который их принёс: график получает высоту с первыми точками. Если секции measurement нет ни в конфиге, ни в данных, страница остаётся вверху. Смена фильтра, группировки или времени секцию в адресе сохраняет, клик по вкладке её сбрасывает.
- В браузере (`localStorage`) хранятся свёрнутые секции, развёрнутые легенды и скрытые линии.

## Обновление

Страница не опрашивает плагин по таймеру, а держит один ждущий запрос ленты изменений ([Плагин hostdash](plugin.md#ожидание-изменений)); отрисовка идёт по своим часам, без сети.

- **Цикл запросов.** В каждый момент — один запрос `/api/series` с measurement раскрытых секций открытой вкладки (у каждого — `seq` его последнего ответа), `after` = `seq` последнего ответа и `wait=25`. Сервер отвечает после следующей записи; страница применяет ответ и сразу шлёт следующий. Overview точек не запрашивает, его запрос ждёт только записи — ради статусов.
- **Смена набора** (другая вкладка, раскрытая или свёрнутая секция): страница сразу рисует вкладку из точек, что у неё есть, обрывает ждущий запрос (`AbortController`) и шлёт новый. Новый measurement идёт с `seq` 0, поэтому сервер отвечает без ожидания.
- **Статусы** (Overview, точки на вкладках, статус в шапке секции), число серий и `silent` — из каждого ответа ленты. Раскладка — только при новой `version` или новом `start`. При новом `start` всё полученное выбрасывается и окно загружается заново.
- **Часы отрисовки** — таймер страницы раз в 1 с, только пока вкладка видна: сдвиг оси времени на графиках (`Chart.slide`) и возраст последней точки в шапках секций. «Сейчас» — `now` последнего ответа плюс время, прошедшее на странице с его прихода. При ширине графика 800 px пиксель оси — около 0,4 с при окне 5 мин и 4,5 с при окне 1 ч.
- **Фоновая вкладка** (`visibilitychange`, `document.hidden`): страница обрывает ждущий запрос и ничего не спрашивает. Когда вкладка снова видна, страница сразу шлёт запрос с сохранёнными `seq`, и лента отдаёт только пропущенные точки.
- **Ошибка сети или сервера:** статус «offline — retrying», повтор через 2 с, затем через вдвое больше, но не реже раза в 30 с; успешный ответ сбрасывает паузу. Смена вкладки или раскрытие секции обрывают паузу и спрашивают сразу. Ошибка первой загрузки тоже видна как «offline». Ошибка при отрисовке — не «offline», а «page error» и сообщение в консоли.
- **Точки** серии на странице — две колонки `Float64Array` с началом, как на сервере (`Points` в `points.js`): 16 Б на точку, дописывание на месте, обрезка по окну сдвигает начало.
- **Графики** держат сведённые линии (`Combined` в `combine.js`) и после ответа пересчитывают только моменты от первого изменённого времени (`Data.changedFrom`), а старые срезают спереди. Если серия линии менялась два раза с прошлой отрисовки или пришла целиком, линия считается заново вся. Если у measurement изменения были, а у серий графика нет, график только сдвигает ось.
- **Часы** сдвигают ось, только когда сдвиг не меньше пикселя.
- Новая раскладка перестраивает только изменившиеся карточки; вкладку целиком — только когда поменялись вкладки или список секций на ней. Счётчики, статусы, причины и `version` в форму раскладки не входят и обновляются на месте. Смена параметров секции перестраивает только её карточку, смена времени только перерисовывает. Правка берёт секцию из текущей раскладки, а не из той, по которой строилась карточка.
- **Новая раскладка и данные:** measurement, у секции которого поменялась конфигурационная часть (поля, графики, единицы), страница спрашивает заново целиком (`seq` 0): секция может показывать поля, которых страница не получала. Точки серий, на которые не ссылается ни одна секция новой раскладки, выбрасываются.
- Чипы Overview пересоздаются, только когда меняются секции, их статусы или ссылки: обновление между нажатием и отпусканием кнопки мыши не съедает клик.

## Код

- `page/`: `index.html`, `style.css` и ES-модули без сборки — `app.js` (вкладки, секции, Overview, опрос), `api.js` (запросы, слияние ленты), `points.js` (колонки точек), `combine.js` (сведение линий, таблицы графика), `model.js` (фильтр, группировка, плитки, предел линий, адрес), `chart.js` (график и легенда на uPlot), `tip.js` (попап), `axis.js` (оси), `tile.js`, `format.js` (единицы, длительности), `dom.js`; `vendor/uPlot.*`. Всё вшито через `go:embed` и раздаётся каталогом.
- Цвета берутся из CSS, тёмная и светлая темы — по `prefers-color-scheme`.
- Тесты чистых функций — `pagetest/*.mjs` через `node --test`; Go-тест плагина запускает их, если есть Node. Решения `app.js` (плитки, предел линий, счётчик, адрес) лежат в чистых функциях `model.js` и проверяются там; инкрементальное сведение сверяется с полным на случайных записях.

## Рассмотренные библиотеки графиков

| Библиотека | Лицензия | Размер min | Почему не она / почему она |
| --- | --- | --- | --- |
| uPlot | MIT | 51 КБ | выбрана: временные ряды на canvas, синхронный курсор (`cursor.sync`), отключаемый масштаб мышью, скрытие линий, полосы между рядами (`bands`), выравнивание рядов по времени (`uPlot.join`); stacked встроенного нет, суммы считает страница |
| Chart.js | MIT | 209 КБ | общего назначения; для оси времени нужен адаптер дат (по памяти) |
| ECharts | Apache-2.0 | 1,1 МБ | умеет всё, но тяжёлый |

Компонентная библиотека (Preact и подобные) при таком размере не нужна: модулей хватает.
